하루의 항해 - GitHub 반영 파일

포함 파일
- index.html: 일간 할 일 대분류 표시 유지, 월간 달력 UI 수정
- manifest.json: 흰색 아이콘 배경 및 PWA 아이콘 설정
- sw.js: 캐시 버전 갱신 및 아이콘 캐시 등록
- icon-180.png: iPhone 홈 화면용 Apple touch icon
- icon-192.png, icon-512.png: PWA 아이콘

적용 내용
1. 일간 할 일에서는 항로(프로젝트) 이름을 별도 배지로 노출하지 않고, 소분류 항목의 대분류 이름(↳)은 유지합니다.
2. 월간 달력의 월 이동 버튼을 해당 월 제목 바로 옆으로 옮겼습니다.
3. 월 이동은 2026년 11월 이전으로 내려가지 않도록 제한했습니다. 따라서 12월에서 이전 달을 누르면 11월을 볼 수 있습니다.
4. 월간 화면은 '일간 할 일도 표시'와 '분류별 보기'만 기본 노출하고, 일정 추가/색상/분류 입력과 안내는 접힌 '일정 추가 및 달력 설정' 안에 배치했습니다.
5. 앱 아이콘의 검은 바깥 배경을 흰색으로 바꾸고 180/192/512 크기로 최적화했습니다.

GitHub 저장소의 기존 파일을 같은 이름으로 교체해 주세요. icon-180.png는 새 파일로 추가하면 됩니다.
